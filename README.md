# ☕ cafe-landing

가상의 동네 카페 "모닝브루"의 간단한 랜딩 페이지입니다. HTML과 CSS만으로 만든 정적 웹페이지예요.

## 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 페이지 본문 (히어로, 카페 소개, 대표 메뉴, 오시는 길, 푸터) |
| `style.css` | 스타일 및 모바일 반응형 설정 |

## 실행 방법

별도 설치 없이 `index.html`을 브라우저에서 열면 됩니다.

## 참고

- 히어로 배경 이미지는 Unsplash 외부 링크를 사용하므로 인터넷 연결이 필요합니다.
- 주소와 전화번호는 임시 값이니 실제 정보로 바꿔 사용하세요.
